## Text styles

Use a named style rather than composing `font-* text-* leading-* tracking-*` by hand: one class sets
the family, size, line height, weight and letter spacing (`custom.css`). Every `h1` takes
`heading-lg` by default.

The `-dense` variant keeps the style on a tighter line height, for a single line packed in a row —
table cells, badges, list items, toolbars. Multi-line text keeps the standard one.
