# Colors

Components only use **semantic colours**: `bg-primary`, `text-muted-foreground`, `border-border`…
Each one maps to a `--base-*` variable whose value switches with the theme (`:root` for light,
`.dark` for dark) in `packages/web-themes/src/mode.css`. The raw palette (`--colors-*-light` /
`--colors-*-dark`) lives in `theme.css` and is never used directly in components.

Both themes are shown side by side below, whatever the toolbar theme.
