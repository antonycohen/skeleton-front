# Colors

Components only use **semantic colours**: `bg-primary`, `text-muted-foreground`, `border-border`…
Each one maps to a `--base-*` variable whose value switches with the theme (`:root` for light,
`.dark` for dark) in `packages/web-themes/src/mode.css`. The raw palette (`--colors-*-light` /
`--colors-*-dark`) lives in `theme.css` and is never used directly in components.

Both themes are shown side by side below, whatever the toolbar theme.

## Status tones

One tone per meaning, shared by every component that carries it (Alert, banners, job bar…):
**important** (indigo) not to be missed but no risk, **success** (teal) an action went through,
**warning** (amber) a consequence to read before acting, **destructive** (rose) something failed or
is blocked. Three roles each: `surface` the tinted fill, `border`, and `on-surface` for the text and
the icon. `destructive` itself stays the solid colour of buttons and errors.
